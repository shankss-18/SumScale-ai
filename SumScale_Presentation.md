## 🔷 What is SumScale?

**SumScale** is a next-generation, multimodal AI-powered intelligence platform designed to help individuals and professionals make sense of complex health, fraud, and data scenarios through conversational AI — without any technical expertise required.

Users upload documents, images, audio recordings, or paste text. SumScale's AI engine extracts structured facts, identifies risks, and provides warm, human-like guidance through a persistent document copilot chat — grounded entirely in the user's own uploaded evidence.

> **Live Demo**: [sum-scale.vercel.app](https://sum-scale.vercel.app)

```
┌───────────────────────────────────────────────────────┐
│                 FRONTEND (Vercel)                      │
│         React 18 + Vite — sum-scale.vercel.app        │
└──────────────────────┬────────────────────────────────┘
                       │  HTTPS REST API
┌──────────────────────▼────────────────────────────────┐
│                 BACKEND (Render)                       │
│      FastAPI (Python 3.13) — sumscale-backend.onrender│
│                                                        │
│  AI Layer:                                             │
│    Groq Llama 3.3-70B  ──fallback──►  Gemini 2.5 Flash│
│    Gemini Vision (image / audio / PDF extraction)      │
│    Google Speech-to-Text (audio transcription)         │
│                                                        │
│  Data Layer:                                           │
│    MongoDB Atlas (cases, chat history, OTP, users)    │
│    JWT HS256 tokens + slowapi rate limiting            │
│    OTP via Twilio SMS + SMTP email                    │
└───────────────────────────────────────────────────────┘
```

### Technology Choices

| Layer | Technology | Why |
|---|---|---|
| Frontend | React 18 + Vite | Fast bundling, HMR, production-ready |
| Backend | FastAPI (async) | High-throughput, Pydantic validation, auto-docs |
| Primary LLM | Groq Llama 3.3-70B | 14,400 requests/day free, fastest inference |
| Fallback LLM | Gemini 2.5 Flash | Automatic failover when Groq is rate-limited |
| Multimodal AI | Gemini Vision | Only model with image + audio + PDF extraction |
| Database | MongoDB Atlas | Flexible schema, cloud-hosted, async motor driver |
| Auth | OTP + JWT | Passwordless, highly user-friendly |
| Deployment | Vercel + Render | Zero-config CI/CD from GitHub main branch |

## 🔒 Security & Quality

- CORS restricted to specific frontend origins
- Prompt injection protection — all user content wrapped in `<user_data>` delimiters
- File validation via python-magic byte-level checks (not extension-based)
- File size cap: 15MB per file, max 5 files per case
- Rate limiting: slowapi with per-IP limits on auth and chat endpoints
- JWT validation on every protected route via FastAPI dependency injection
- 24 pytest unit tests covering auth, cases, chat, health, and seed endpoints (100% pass rate)

## 🚀 Planned Features — Roadmap

---

### 🛡️ Feature 1 — Fraud Verification Module

**Purpose**: Instantly verify whether a URL, phone number, IP, or domain is malicious using 4 parallel threat-intelligence APIs.

**How it works**:
1. User enters a suspicious entity (phone, link, domain, IP)
2. SumScale runs 4 async checks in parallel:
   - Google Safe Browsing API v4 — malware and phishing URL detection
   - VirusTotal API v3 — 70+ antivirus engine consensus vote
   - WhoisXML — domain age check (new domains = high risk)
   - IPQualityScore — VOIP and disposable phone detection
3. Results aggregated into a FraudVerdict: `safe / suspicious / malicious`
4. Results cached in MongoDB for 24 hours (avoids re-hitting free-tier API rate limits)

**Risk Logic**:
- `malicious` if: Safe Browsing hit OR VirusTotal >3 engines OR domain age <7 days
- `suspicious` if: domain age <30 days OR phone is disposable/VOIP with risk score >75
- `safe` otherwise

**Frontend**: FraudEvidencePanel.jsx — evidence cards with source logo, finding, and colored badge

**New Endpoint**: `POST /api/fraud/verify`

---

### 🔗 Feature 2 — Cross-Modal Fraud Case Fusion

**Purpose**: Link multiple pieces of evidence (screenshot, voice note, SMS) from the same fraud incident into one unified scammer profile — even if each piece alone is inconclusive.

**How it works**:
1. User uploads multiple artifacts (image, audio, text) to a fraud case
2. SumScale extracts entities from each: phones, URLs, UPI IDs, amounts
3. A single Gemini fusion prompt analyzes all artifacts together and extracts the unified scammer profile
4. Feature 1's `verify_entity` is run on every unique entity across ALL artifacts
5. Final fused verdict stored back to the case with full corroboration note

**Frontend**: CaseTimeline.jsx — chronological artifact viewer with Fuse & Analyze button

**New Endpoints**: `POST /api/fraud/cases/{id}/add-artifact` and `POST /api/fraud/cases/{id}/fuse`

---

### 🔔 Feature 3 — Proactive Alerts & Shared Intelligence Layer

**Part A — Critical Health Alerts (Twilio SMS)**

When AI finds a critical health reading in uploaded documents, SumScale automatically sends an SMS to the user's registered emergency contact:

> *"SumScale Alert: [User]'s recent Fever reading is 104F, outside normal range. Please check in."*

- Emergency contact phone + consent flag stored in user profile
- Rate-limited: max 1 alert per metric per 24 hours (MongoDB audit log)

**Part B — Shared Fraud Intelligence Database**

Community-powered, privacy-preserving database of flagged entities:
- Every confirmed-malicious entity upserted with hashed user ID (privacy preserved)
- `verify_entity` checks this database FIRST — free, instant, no API quota
- Auto-flags entities at `report_count >= 3`
- Public stats endpoint: `GET /api/fraud/intel-stats`

**Frontend**:
- AlertSettings.jsx — emergency contact opt-in form in Profile
- IntelBanner.jsx — "This number has been reported by 14 other users in the last 30 days" shown instantly before external API results load
